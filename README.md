# Playwright----CI-CD
A scalable end-to-end test automation framework built with Playwright using the Page Object Model (POM) design pattern. The framework is designed for maintainable, reusable, and reliable automated testing, with CI/CD integration to execute tests automatically as part of the software delivery pipeline.

Key Features
Playwright-based end-to-end test automation
Page Object Model (POM) architecture
Reusable page classes and test components
Test data management
Environment-based configuration
Automated test execution and reporting
CI/CD pipeline integration
Cross-browser testing
Easy-to-maintain and scalable framework structure

The project demonstrates how modern QA automation can be integrated into a CI/CD workflow, enabling automated regression testing and faster feedback throughout the development lifecycle.


## Automated Test Scenarios Covered

Registration & Login
* Verify successful user registration ✅
* Verify successful user login ✅
* Verify registration with an already registered email ✅
* Verify login with invalid credentials ✅
* Verify logout functionality ✅

Search
* Verify product search with a valid product name ✅
* Verify search with an invalid product name ✅
* Verify search with an empty search field ✅
* Verify user can open a product from search results ✅
* Verify user can navigate to a product details page ✅
* Verify product details are displayed correctly ✅
* Verify user can add multiple different products to the cart ✅ 
* Verify product can be added to the cart from the product details page ✅

Wishlist
* Verify user can add a product to the wishlist ✅
* Verify product can be removed from the wishlist ✅
* Verify wishlist item can be added to the cart ✅
